# Tic Tac Toe (Python)

A simple command-line Tic Tac Toe game built using Python.
This project demonstrates basic programming concepts like functions, loops, and condition handling in a fun way.


## 🧠 Functions Overview

* **print_board(game_board)** → Displays the game board
* **player_input()** → Assigns markers (X or O)
* **place_marker(game_board, marker, position)** → Places marker on board
* **win_check(game_board, mark)** → Checks win condition
* **choose_first()** → Decides which player starts
* **space_check(game_board, position)** → Checks if spot is empty
* **full_board_check(game_board)** → Checks if board is full
* **player_choice(game_board)** → Handles player input
* **replay()** → Restarts the game
